# Vorlage: Protokoll Generalversammlung Yetnet Rupperswil

`Protokoll_Generalversammlung_YeRu_2026_Vorlage.docx` ist eine Word-Vorlage für das
Protokoll der Generalversammlung 2026. Struktur, Schrift (Arial 13 pt, Titel in
Kapitälchen) und Aufbau sind dem Protokoll der GV 2025 nachgebildet.

## Verwendung

* Alle **grau gesetzten Texte in eckigen Klammern** sind Platzhalter und werden
  beim Ausfüllen ersetzt (Suche nach `[` findet sie alle).
* Nach dem Ausfüllen die Textfarbe auf Schwarz setzen (Alles markieren →
  Schriftfarbe „Automatisch“).
* Die Traktandenliste ist automatisch nummeriert; die Kapitelüberschriften
  (1.–8.) sind fest geschrieben und bei Änderungen der Traktanden anzupassen.
* Jahreszahlen sind auf 2026 vorbereitet (Rechnung 2025, Voranschlag 2026,
  48. Generalversammlung).

## Neu erzeugen

```bash
npm install docx
node build_protokoll_vorlage.js Protokoll_Generalversammlung_YeRu_2026_Vorlage.docx
```
